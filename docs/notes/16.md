## Replay loop

For each season in `test_seasons ∪ continuity_seasons`:

1. `rating_engine.initialize_season` at pre-Week-1 `as_of`
2. Offseason mapping retrain on all revealed labels (`seasons < Y`)
3. For each week: decision `as_of` (default Tuesday 06:00 ET) → features →
   predict → record vs as-of lines **and** closing lines → reveal → update
   ratings. Mid-season retrains fire at configured `retrain_weeks`.

Predictions table columns: `prediction_id`, `game_key`, `as_of`,
`model_version`, `feature_hash`, predicted quantities, as-of/close lines with
`line_source` + `n_books`, realized outcomes, `exclude_from_headline`,
`is_week1`, `retrain_epoch`, `continuity_season`.

## Decisions / ambiguities

1. **FeatureProvider / RatingEngine protocols.** Task says walkforward only;
   Stage-1 wiring is injected via protocols. `RunningMarginRatingEngine` is a
   toy continuity stub for placeholder E2E — production will inject a
   state-space + priors adapter without changing the harness loop.
2. **game_key.** Prefer an explicit `games.game_key` column; else
   `{season}:{home_id}:{away_id}:{YYYY-MM-DD}`. School-name keys via
   `make_game_key` remain the caller's responsibility when joining Odds API.
3. **Decision clock.** Reimplemented locally (Labor Day Week-1 Monday +
   weekday/hour in `as_of_tz`) rather than importing
   `tuesday_0600_et_for_week`, so custom as-of configs work for Task 23
   ablations. Default matches the Odds historical Tuesday 06:00 ET point.
4. **Line ladder.** Snapshot seasons ≥2021: snapshot `< bound` → nearest
   earlier (tolerance logged as `_fallback`) → null. CFBD never enters that
   ladder. Pre-2021: CFBD open (as-of) / close (closing).
5. **Shifted-label chance.** Baseline = MAE of predicting the sample mean of
   the shifted labels (best constant). Placeholder sits at chance; a cheater
   reading `leaked_margin` fails the hook.
6. **Retrain features.** Placeholder `fit` ignores feature frames; harness
   passes empty features at retrain gates. Task 17 predictors will receive
   real OOF feature frames when wired.
7. **Coverage.** New module at ~80% line coverage (branch gaps on rare line /
   empty-path arms). Overall repo gate still met.
