## Decisions / ambiguities

1. **Null discipline.** Missing sources stay NaN with `null_policy: indicator`
   (except `portal_era`, always 0/1). Never `fillna(0)`. Pre-2021
   `portal_net_rating` is always null; in-era with no rated transfers is also
   null (wide-uncertainty), not zero.
2. **Recruiting weights.** Default `(0.1, 0.2, 0.3, 0.4)` for years
   `[S-3, S-2, S-1, S]`. Missing years drop and remaining weights renormalize;
   all-missing → null. Configurable via `RosterConfig.recruiting_weights`.
3. **Portal net.** `sum(inbound ratings) − sum(outbound ratings)` for the
   season with `event_time < as_of`; unrated transfers ignored in the sum;
   no rated touch → null.
4. **HC identity.** Tenure uses `(first_name, last_name)` continuity on
   `team_id` (CFBD `coach_id` embeds season). `new_hc_flag = 1` when tenure ≤ 1.
5. **OC/DC.** From `configs/coordinators.yaml` only. Non-seeded schools → null
   + indicator. First observed season for a staff name counts as a change.
   Spotlight P5 programs have real-ish names; remaining P5 use stable
   placeholders pending hand verification.
6. **OL returning starts — skipped.** Staged `rosters` has position/year but
   no starts/career-start fields; cannot derive without a new source.
7. **QB status.** Entity id `game_id:team_id`; values starter=1, backup=0,
   unknown=null+indicator. Versioned append; as-of takes latest
   `event_time < as_of`. Scrape stub documents prospective ESPN/school scrape
   path; v1 is manual only (§3.4).
8. **QB-value estimate delta** (DESIGN §4.5) deferred — Task 12 deliverable
   lists status table/CLI, not the value delta.
