## AMENDMENT — Task 22B-FIX

**Record:** Task 22B was reported as passing on a broken leakage test. A green
suite is not the same as a working system; Task 23's memo must be read with
that in mind.

### BLOCKER 1 root causes (written before code changes)

**(a) MAE ≈ 15348.57 — not a bad model, a degenerate ElasticNet member.**

Evidence from replaying
`tests/unit/test_task22b.py::test_production_infoset_determinism_shifted_label`:

- Feature matrix at the shifted as-of is finite and non-zero (rating EPA diffs
  on the order of 1e-2 to 3e-2; not all-NaN, not all-zero).
- Feature signature is aligned (15 rating columns; `game_id` excluded via
  `META_COLUMNS`).
- Heads are fitted (`ProductionEnsemblePredictor._fitted=True`; LGBM returns
  the training-mean margin ≈ 3.625 on every row).
- Predictions are numerically in "margin" units but absurd in magnitude.

Root mechanism: `ElasticNetMuHead` standardizes selected features. On the
8-row synthetic fit, `rating_uncertainty` has near-zero train variance
(`StandardScaler.scale_ ≈ 1.15e-6`). At shifted predict time the same column
is ≈ 0.309 vs train mean ≈ 0.213 → standardized value ≈ **8.3e4 σ**. With
coef ≈ 0.37 that alone yields ElasticNet preds ≈ **30,700**. The production
ensemble averages LGBM (≈ 3.6) with that finite-but-absurd ElasticNet output
→ ensemble pred ≈ **15,350** → MAE ≈ **15,348**.

So: not NaN features, not column misalignment, not an unfitted head, not a
unit-conversion bug. It is **OOD explosion of the ElasticNet member via
near-constant `rating_uncertainty`**, accepted by
`ProductionEnsemblePredictor.predict` because the fallback only rejected
non-finite values (`np.isfinite`), not non-credible magnitudes.

Files: `src/ncaa_quant/models/heads/elasticnet.py` (`_predict_estimator` /
scaler); entry into the reported score is
`src/ncaa_quant/evaluation/production_stack.py`
(`ProductionEnsemblePredictor.predict` ensemble blend). ElasticNet itself is
outside the 22B-FIX sanctioned list; the credibility gap in the blend path is
in `production_stack.py` (sanctioned when root cause is here).

**(b) Chance baseline 6.75 — sample-mean MAE on n=4 synthetic games, not CFB league chance.**

`run_shifted_label_test` called `chance_mae_constant(y, constant=y.mean())` on
the four past-game margins `[9, -1, -1, 16]`. MAE of predicting that sample
mean is exactly **6.75** (and coincidentally equals MAE vs 0 on this set).
It was never a hardcoded CFB constant and never league-mean chance (~13–14 on
real margins). It is correct-by-construction chance on a tiny low-variance
synthetic eval set — which is why 6.75 looked "too good" next to real CFB.

**One-sided pass condition failure mode (on record):**
`passed = model_score >= chance_score * (1 - tolerance)` (relative). Any
predictor returning infinity (or MAE 15348) **passes**. The gate only fails
models that beat chance; it cannot certify that the pipeline is wired.

### BLOCKER 1 repairs

- `ProductionEnsemblePredictor.predict` now rejects ElasticNet member outputs
  with `|pred| > MAX_CREDIBLE_MARGIN_PRED` (80.0) the same way it rejects

- New gate: `tests/leakage/test_shifted_label.py` — chance = MAE of the
