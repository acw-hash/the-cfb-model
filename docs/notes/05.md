# Task 05 — CFBD ingestion and historical backfill (AUDIT-11 / amended)

## Built

Amended Task 5 (AUDIT-6 event_time rules) on top of the existing CFBD client:

- `src/ncaa_quant/ingestion/cfbd.py`: typed httpx `CFBDClient` with tenacity
  retries (5×, exp backoff, 429/5xx/timeout only), QPS throttle, remaining-header
  budget guard. Raw archival before parse. Per-endpoint normalizers → pandera
  `ParquetStore` partitions. Resumable backfill (`--force`) and `--incremental`.
- **AUDIT-6 event_time:** completion timestamp when present on the payload;
  else kickoff + 5h (7h when OT flagged). `games.event_time_estimated` records
  the estimate (ADR 0004). Plays/drives/advanced inherit resolved
  `game_event_by_id` from staged games.
- OT detection: line-score arrays length > 4, or notes matching `OT` /
  `overtime` (including `2OT`).
- Completion keys probed (forward-compatible; CFBD v1 ships none): `end_date`,
  `endDate`, `completed_at`, `completedAt`, `finish_date`, `finishDate`,
  `end_time`, `endTime`.
- Shared team helpers / Odds↔CFBD crosswalk remain in `ingestion/teams.py` and
  `odds_api.py` (Task 4). Postpone fixture lives in `tests/unit/test_odds_api.py`.
- Schema: `GamesSchema.event_time_estimated`; GE games column set updated.
- CLI: `ncaa-quant ingest cfbd --seasons YYYY[-YYYY] [--endpoints …] [--force]`
  and `--incremental`.
- Tests in `tests/unit/test_cfbd.py` (regulation / OT / completion fixtures,
  resumability, kill-mid-backfill).

## event_time assignment table

| Endpoint / table | `event_time` | `event_time_estimated` | Notes |
|---|---|---|---|
| `games` | completion ts if present; else kickoff+5h (7h if OT) | False / True | Flag on games only (ADR 0004) |
| `plays`, `drives`, `advanced_box` | same resolved instant as parent game | n/a | Via `game_event_by_id` |
| `lines_historical` | kickoff `start_date` | n/a | Conservative latest for open/close |
| `talent`, `returning_production`, `recruiting`, `teams`, `venues`, `coaches`, `rosters` | `{season}-08-01T00:00:00Z` | n/a | Documented preseason |
| `portal` | `transfer_date` when present; else Aug 1 preseason | n/a | Missing transfer dates → preseason |

`ingested_at` = pull time. `source_version` = `cfbd_v1`.

## Decisions / ambiguities

1. **Schema widen** for `games.event_time_estimated` despite "cfbd.py only" —
   recorded in `docs/adr/0004-event-time-estimated-schema.md`. GE suite column
   set updated as a necessary consequence.
2. **CFBD has no completion timestamp** today → all 2023 staged games use the
   kickoff+duration estimate (`event_time_estimated=True`). Hook retained for
   future payload fields.
3. **OT duration = 7h** (5h + 2h cushion) — spec said "more when OT"; exact
   extra hours unspecified.
4. Prior Task 5 notes (3.5h, no estimate flag) are superseded by this amendment.
