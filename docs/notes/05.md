# Task 05 — CFBD ingestion and historical backfill

## Built

- `src/ncaa_quant/ingestion/cfbd.py`: typed httpx `CFBDClient` with tenacity
  retries (5×, exp backoff, 429/5xx/timeout only), QPS throttle from
  `data.cfbd_requests_per_second`, and remaining-header budget guard (default
  reserve 10). Raw archival to `data/raw/cfbd/{date}/{endpoint}_….json` before
  parse. Per-endpoint normalizers → pandera-validated `ParquetStore` partitions.
  Resumable backfill (`--force` to overwrite) and `--incremental` mode.
- Shared team helpers moved to `src/ncaa_quant/ingestion/teams.py` (sanctioned);
  `odds_api.py` re-exports them.
- `TalentSchema` + registry / `REFERENCE_TABLES` / `docs/data_layout.md` (required
  for `/talent`; Task 3 notes already allowed widening).
- CLI: `ncaa-quant ingest cfbd --seasons YYYY[-YYYY] [--endpoints …] [--force]`
  and `ncaa-quant ingest cfbd --incremental`.
- Tests in `tests/unit/test_cfbd.py`.

## event_time assignment table

| Endpoint / table | `event_time` | Notes |
|---|---|---|
| `games`, `plays`, `drives`, `advanced_box` | `start_date + GAME_DURATION` (3.5h UTC) | CFBD has no reliable completion timestamp; 3.5h is a documented estimate |
| `lines_historical` | kickoff `start_date` | Conservative latest for open/close when open timestamps are absent |
| `talent`, `returning_production`, `recruiting`, `teams`, `venues`, `coaches`, `rosters` | `{season}-08-01T00:00:00Z` | Documented preseason instant |
| `portal` | `transfer_date` when present; else Aug 1 preseason | Missing transfer dates flagged as conservative |

`ingested_at` = pull time. `source_version` = `cfbd_v1`.

## Decisions / ambiguities

1. **`/teams` included** though not in the task bullet list — required for
   `TeamsSchema` and school→`team_id` resolution on reference endpoints.
2. **`/games/teams` archive-only** — no staged box schema; completion tracked via
   `data/raw/cfbd/_complete/games_teams/…` markers.
3. **Empty partitions** written with `validate=False` so empty weeks still mark
   complete for resume (pandera dtype pain on zero-row frames).
4. **Returning defense_pct** often absent from CFBD; left null. Offense falls back
   to overall `percentPPA.total` when offense-specific is missing. Percents > 1
   are treated as 0–100 and scaled to `[0, 1]`.
5. **Games resume**: if any staged games exist for the season and `--force` is
   off, the games API is not re-called (week list comes from staged data).
6. **Week discovery** prefers CFBD `week` on payloads; falls back to
   `week_of(start_date, season)`.
7. **FBS filter** on `/games` and `/plays` via `classification=fbs`.
9. **Dirty CFBD fields coerced to null** in normalizers: period 0, down > 4,
   yards_to_goal outside `[0, 100]` — keep schema ranges intact.
