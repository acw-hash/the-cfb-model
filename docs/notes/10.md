# Task 10 — Efficiency feature builders

## Built

- `src/ncaa_quant/features/builders/efficiency.py` — ridge opponent adjustment
  (`y = off_i − def_j + hfa + ε` with L2 toward zero), FCS pooling, Bayesian
  shrinkage `n/(n+k)`, EWMA / last-3 deltas, game-level observation builder,
  and `EfficiencyFeatureBuilder` (PIT via `filter_event_time` + injectable
  `history` for `pit_audit`).
- `src/ncaa_quant/features/registry.yaml` — 48 efficiency features
  (`adj_{off|def}_{metric}_{std|ewma|l3d}`) with non-empty hypotheses.
- Config: `data.ridge_lambda_efficiency: 5.0` (untuned PLACEHOLDER) in
  `configs/data.yaml` + `DataConfig`.
- Tests: `tests/unit/test_efficiency.py` (synthetic recovery, shrinkage,
  EWMA, FCS pool, PIT). Updated Task 9 empty-registry assertion.

## Decisions / ambiguities

1. **Ridge λ = 5.0.** Documented default; not tuned (walk-forward CV later).
2. **FCS pooling.** All non-FBS classifications (`fcs` / `ii` / `iii` /
   `other`) map to a single `FCS_TIER` entity — sparse opponents share one
   rating (DESIGN §1.5).
3. **Prior seam.** `resolve_priors(..., prior_lookup=None)` shrinks toward the
   league mean of fitted ratings until Task 15 supplies real preseason priors.
4. **Game-level ridge.** Observations are per-(game, offense) aggregates after
   garbage filter, on **rush+pass snaps only** (ST/penalty excluded). Spec
   allows play or game set; game-level is stabler for weekly features.
5. **Forms.** `std` = shrunk mean of game-level adjusted values; `ewma` =
   EWMA of those values (half-life from config; explosiveness uses the longer
   knob); `l3d` = last-3 mean − season mean.
6. **Field position.** Mean starting yards-from-own-goal
   (`100 - start_yards_to_goal`); finishing = mean points on drives with
   `start_yards_to_goal ≤ 40`.
7. **Scope extras.** Deliverables required `registry.yaml`, tests, notes, and
   a config λ — touched those plus the obsolete Task 9 empty-registry test.
   Did not patch Task 3 `as_of_join` / staged plays schema gaps (Task 8 notes).
