## Part 0 — corrections

### 1. Chance gate reverted → sign gate + skill flag

The D5 run-failing gate `LL > ln 2` was specified on a wrong premise.

**Why it was wrong.** Let `d = SD(μ − market)` and `s` be predictive σ. Under **zero skill** against the spread, the cover edge is noise with spread `d`, and

\[
\mathbb{E}\bigl[-\ln \Phi(dz/s)\bigr]
\]

averaged over outcomes **exceeds** \(\ln 2\) for any \(d > 0\). A model with honest σ and no ATS edge **must** score above 0.693 on ATS; that is arithmetic, not a defect. On this sample ATS LL=0.813 with `sd(μ−market)≈10.1` — exactly the pattern the bad gate would have failed.

**Replacement (shipped):**

| gate | failing? | rule |
|---|---|---|
| **SIGN GATE** | yes | if `LL(1−p) < LL(p) − ε` on any derived market → run fails |
| **SKILL FLAG** | no | report `LL(p)`, `LL(1−p)`, `sd(μ−market)`; record skill vs chance without blocking |

Acceptance: inverted-probability table trips `SignInvertedMarketError`; healthy above-chance ATS no longer fails.

Not a schema change. CFBD closes exist in `lines_historical` for **2014–2025**. `resolve_lines_for_games` gated seasons `≥2021` to Odds snapshots only, and the task23 backtest passed `snapshots=None` → null `spread_close`/`total_close` on 2021–2025. **Fix:** evaluation-only join (`join_cfbd_closes_for_evaluation` / `cfbd_close_eval`) fills null closes from CFBD medians. Walkforward `closing=True` now falls back to CFBD when snapshots miss; `closing=False` (bet-time features) still never leaks CFBD into ≥2021.
