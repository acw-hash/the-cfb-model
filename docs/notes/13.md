# Task 13 — Elo baseline

## Built

- `src/ncaa_quant/ratings/elo_baseline.py` — margin-aware Elo (FiveThirtyEight-style
  MOV × autocorrelation), HFA, between-season regression, weekly/postgame/
  preseason history table, walk-forward `(K, mov_factor)` grid scan, one-step
  log-loss + ATS-vs-closing helpers, Spearman vs SP+ helper.
- Tests: `tests/unit/test_elo_baseline.py`.
- Acceptance harness (one-off): `scripts/_elo_acceptance_13.py` with cache under
  `data/tmp/elo_acceptance_13/` (not staged lake tables).

## Formula (documented in module docstring)

```
elo_diff = elo_home - elo_away + (0 if neutral else hfa)
P(home)  = 1 / (1 + 10^(-elo_diff/400))
MOV      = ln(|PD|+1) * (mov_factor / ((ELOW-ELOL)*mov_autocorr + mov_factor))
shift    = K * MOV * (S_home - P(home))
elo_home ← elo_home + shift;  elo_away ← elo_away - shift
```

Between seasons: `elo ← (1−r)·elo + r·mean` with default `r = 1/3`, `mean = 1500`.
ATS mapping: `pred_home_margin = elo_diff / elo_per_point` (`elo_per_point=25`).

## Decisions / ambiguities

1. **Defaults after scan.** Tuned on 2014–2024 FBS-vs-FBS games:
   `K=30`, `mov_factor=2.8` (grid: K∈{10,15,20,25,30} × mov∈{1.5,2.2,2.8}).
   HFA=55, regression=1/3, autocorr=0.001 left at 538-ish values (not scanned).
2. **FBS-only updates.** When a `teams` frame is supplied, only games with both
   sides classified `fbs` that season update Elo (avoids FCS-cupcake inflation).
3. **History kinds.** `postgame` (per game), `weekly` (last postgame that week),
   `preseason` (week=0 after regression). PIT consumers use
   `rating_history_asof(..., kind='postgame')` with `event_time < as_of`.
4. **No SP+ / multi-season games in staged lake.** Prior ingestion only staged
   2023. Acceptance fetched CFBD live via existing `CFBDClient` + normalizers —
   did **not** extend `ENDPOINT_SPECS` / staged schemas (out of scope). SP+ is
   still not a staged table; needed for the §15 sanity check only.
5. **Tune vs evaluate.** One-step log-loss is pregame by construction on a single
   chronological pass; the same pass supplies the reported baseline metrics
   (no nested Optuna). ATS uses median closing spread across books.
6. **Scope extras.** Tests + notes + acceptance script. Did not touch
   `configs/ratings.yaml` / `RatingsConfig` (Elo params live on `EloConfig`).
