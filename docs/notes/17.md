# Task 17 — Mapping-layer model heads

## Built

- `src/ncaa_quant/models/heads/` — Level-0 ensemble members per DESIGN §5.2:
  - `base.py` — `BasePredictor` (fit/predict/save/load), feature-signature
    contract, monotone-constraint helpers, predict-time feature bank
  - `weights.py` — season time-decay sample weights (default half-life **2.0**)
  - `margin.py` / `total.py` — LightGBM μ heads; margin applies + verifies
    monotone constraints on rating-differential features
  - `quantile.py` — LightGBM quantiles
    `{0.05,0.1,0.25,0.5,0.75,0.9,0.95}` with crossing sort + warning
  - `sigma.py` — LightGBM on `|OOF residual|` (`abs_residual_*` labels)
  - `xgboost_mu.py`, `catboost_mu.py` — diversity μ (GPU via `train.use_gpu`)
  - `elasticnet.py` — ElasticNet on top-30 (configurable) |corr| features
  - `ngboost_dist.py` — NGBoost Normal(μ, σ) for margin and total
- Tests: `tests/unit/test_model_heads.py`

## Decisions / ambiguities

1. **Task 16 empty retrain features (prior-task gap).** Walk-forward still
   passes `pd.DataFrame()` at retrain gates (notes/16.md item 6). Did **not**
   patch `walkforward.py`. `BasePredictor` banks feature rows on every
   `predict` and reconstructs X from `labels.game_id` at `fit` when the
   harness supplies empty features. Production should eventually pass real
   as-of feature frames at retrain; the bank is an adapter, not the long-term
   contract.
2. **Default season half-life = 2.0.** Spec said "configurable, default
   documented" without a number. Two seasons → weight 0.5.
3. **Rating-diff monotone tokens.** Features whose names contain
   `rating_diff`, `elo_diff`, `offense_rating_diff`, or `defense_rating_diff`
   get constraint `+1` on margin μ (LightGBM + XGBoost + CatBoost). Totals/σ:
   all zeros.
4. **Monotone verification.** After LightGBM fit, require
   `booster.dump_model()["monotone_constraints"]` to equal the vector we
   passed (guards silent ignore of malformed specs).
5. **ElasticNet top-K.** Absolute Pearson correlation with y on the train
   frame; ties broken by feature name. Default `top_k=30`.
6. **σ labels.** Caller builds `abs_residual_margin` /
   `abs_residual_total` via `abs_residual_labels` from OOF μ predictions.
   Situational / rating-uncertainty features are whatever the feature
   provider supplies (fixture uses `rating_uncertainty`, `rest_proxy`).
7. **Cold start.** Unfitted `predict` returns zeros (μ) or ones (σ) so the
   harness can emit Week-1 rows before any reveal/retrain.
8. **GPU.** `HeadTrainConfig.use_gpu=False` by default (CI/native Phase 1).
   XGB uses `device=cuda`; CatBoost uses `task_type=GPU` when enabled.
