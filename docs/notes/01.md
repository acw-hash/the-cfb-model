# Task 01 — Repository scaffold

## Built

- Full §11 directory tree under `src/ncaa_quant/` with package `__init__.py`
  one-liners; empty dirs use `.gitkeep` (`configs/models/`, `data/*`, `notebooks/`,
  `tests/{unit,integration,leakage,golden}/`).
- `pyproject.toml` + `uv.lock` (Python 3.11, major-pinned deps per AUDIT-6:
  includes `dvc`, `scipy`, `shap`, `jinja2`, `plotly`; optional `research` extra
  with `numpyro`/`jax`/`pymc-bart` via `uv sync --extra research`).
- Tooling: ruff (line length 100), mypy strict on `src/`, pytest coverage gate
  ≥80% on `src`, registered `pytest.mark.live` — CI and default `make test`
  run with `-m "not live"`.
- Typer CLI command groups matching Makefile verbs (`ingest|features|ratings|
  train|predict|backtest` plus later groups); Makefile mirrors install/lint/
  typecheck/test/format/clean and pipeline verbs.
- CI workflow, pre-commit (ruff, ruff-format, mypy, trailing-whitespace,
  check-yaml, detect-private-key), `.gitignore`, `.env.example`
  (`CFBD_API_KEY`, `ODDS_API_KEY`).
- Docs: `mkdocs.yml`, `docs/index.md`, ADR 0001, this notes file.
- `Dockerfile` (NVIDIA CUDA 12.x Ubuntu 22.04, non-root, uv) and
  `docker-compose.yml` (app, MLflow **file-store** backend + artifact volume,
  Prefect, named `data` volume). Compose is a deferred artifact; Phase 1 runs
  natively per `.cursorrules` — build only, do not run containers.

## Decisions / ambiguities

1. **AUDIT-6 dependency set is the approval:** Task 1's list (including dvc/
   scipy/shap/jinja2/plotly and the `research` extra) is the approved set under
   `.cursorrules`; further deps need an explicit amendment.
2. **Empty config YAMLs:** Tree placeholders under `configs/`; Task 2 owns real
   layered contents.
3. **Coverage:** `test_scaffold.py` imports packages and exercises CLI `--help`
   / stub groups toward the 80% gate on new scaffold code.
4. **Docker:** Acceptance requires `docker build .` succeeds; runtime remains
   native uv for Tasks 1–24. MLflow compose uses `file:/mlflow/mlruns` (not
   SQLite) per §10 / AUDIT-6 multi-writer note.
5. **Hatchling:** Default src-layout discovery (no explicit `packages=` override).
6. **Live tests:** Marker registered now; no live tests exist yet. Exclusion is
   wired so later network tests cannot leak into CI.
7. **numba/numpy overrides for shap:** `shap` pulls `numba`; without overrides the
   resolver left numpy at 2.2 and broke `make typecheck` under mypy strict.
   `[tool.uv] override-dependencies` pins `numba>=0.64,<0.65` (NumPy 2.4 support)
   and `numpy>=2.4,<3`. `uv sync --extra research` / pymc-bart may still need a
   dedicated env — revisit when research sprints start.
