# Task 05B — Historical odds backfill

## Built

- Extended [`src/ncaa_quant/ingestion/odds_api.py`](../../src/ncaa_quant/ingestion/odds_api.py):
  historical client (`GET /v4/historical/sports/.../odds`), envelope parse,

- Schema: `OddsSnapshotsSchema` gained the three Task 5B columns.

- Tests covering returned-vs-requested `event_time`, tolerance by era, budget-bucket
  isolation, resumability / mid-slot crash, estimator arithmetic, envelope parse,
  live↔historical dedupe, calibration abort, reconcile/coverage helpers.

## event_time discipline

| Path | `event_time` |
|---|---|
| Live | `captured_at` at ingest |
| Historical | Envelope **returned** `timestamp` — never the request `date` |

As-of coverage tolerance: ≥10 min before 2022-09-01, ≥5 min after.

## Credit buckets

- Live floor: `odds_rate_limit_reserve` (50). Historical refuses any call that would
  leave remaining below that floor after a 30-credit debit.
- Historical ceiling: `odds_historical_credit_ceiling` (**60000**); refuse without `--force`.
- Credits/call: `odds_historical_credits_per_call` (30 = 10 × markets × regions).
