## Part 1 — ATS / OU probability path

### Trace (code references)

| step | location | convention |
|---|---|---|
| Stored spread | CFBD `lines_historical.spread` / `spread_close` | **Home-relative**: negative when home is favored (verified vs consensus) |
| Cover event | `metrics.ats_home_outcomes` | home covers iff `margin + spread > 0`; pushes → NaN |
| Gaussian P(cover) | `d3_eval._market_probs`, D4 revive | `Φ((μ + spread) / σ)` |
| MC P(cover) | `simulate.spread_cover_probs` | `P(M + spread > 0)`; push = `P(==0)` |
| Binary emit (fix) | `production_stack.predict` | `two_way_side_prob(...)` so net-of-push Bernoulli |
| Line snapshot for probs | `_lookup_closes` / `spread_close` | **close** |
| Line for grading | `spread_close` | **same close** on this archive (`spread_asof == spread_close`) |
| Key-number kernel | `fit_key_number_kernel` → `sample_joint` | applied in production MC; **not** on the Gaussian uncalibrated LL path |

OU: `Φ((μ_T − total) / σ_T)` / `P(T > total)`; no home/away orientation.

### Hypotheses

| H | ATS | OU |
|---|---|---|
| H1 sign inverted | **REJECTED** — LL(1−p)=0.856 (worse); not near 0.58 | N/A |
| H2 snapshot mismatch | **REJECTED** — asof=close rate 1.0 | same |
| H3 push misallocated | **REJECTED** on continuous path (p_push=0). Production now always emits two-way | same hygiene |
| H4 kernel orientation | **REJECTED** — Gaussian eval path has no kernel | same |
| H5 neutral-only swap | **REJECTED** — not localized to neutral | N/A |

**Root cause:** cover-edge `(μ + S)` has ~0 correlation with cover outcomes (hard
ATS accuracy ≈ 50.6%) while `|μ+S|/σ` still produces extreme probabilities.
Shared with OU (weak edge, overconfident). ML stays healthy because `Φ(μ/σ)`
targets wins, not covers against an efficient close.

**Path fixes shipped:** (1) two-way side probs in production MC; (2) push
excluded when fitting calibrator labels; (3) §19 consistency strengthened to
the MC path + nonzero-spread Gaussian/H1 guard; (4) chance-level gate
`assert_derived_markets_not_anti_informative` (trips on planted
anti-informative table in `tests/unit/test_d5_gates.py`).

The chance gate **fails** this scored table for ATS and OU (reliably wrong, not
merely uninformative). **Superseded by D6:** that gate was arithmetically
wrong under zero ATS skill with d=SD(μ−market)>0; replaced by a sign gate
(run-failing) + skill flag (warning only). See `docs/notes/D6.md`.

### §19 consistency (strengthened)

Old check was tautological without a kernel (`Φ(μ/σ)` vs itself). New check
uses `moneyline_probs` vs `spread_cover_probs(0)` on `sample_joint` draws, plus
nonzero-spread agreement with `Φ((μ+S)/σ)` (and fails if the inverted-sign
formula fits better). Continuous subsample: **within tolerance**.

## Part 3 — powered encompassing test (pre-registered)

**Pre-registration timestamp:** 2026-08-06T12:00:00-04:00  
**Status:** written **before** ingesting Odds API 2021–2025 Tuesday/close
snapshots for the powered test. (CFBD closes already sit in
`lines_historical`; they are not yet the bet-time / CLV instrument.)

Config: `configs/eval/encompassing.yaml`  
Runner: `ncaa_quant.evaluation.d5_eval.run_encompassing_evaluation`

### Decision rule (do not edit after seeing multi-season results)

1. **n:** joint overlap must reach the power target for the declared effect —
   at the D4 SE scale, **n ≥ 4986** to detect b2=0.10 at 80% power (or
   re-estimate SE on the expanded sample and recompute). Per-season minimum
   **400** games with finite consensus spread.
2. **b2 threshold:** declare a fundamental-model edge only if joint b2 > 0
   with block-bootstrap two-sided p < 0.10 **and** 95% CI excludes 0.
3. **Stability:** at least **3** seasons with reliably positive b2
   (p < 0.10 within season), not a single-season fluke.
4. **Stop rule (move to market-aware stack per DESIGN §13.1):** if after the
   powered sample the joint b2 CI lies entirely below **+0.05** (no material
   positive weight on stack μ) **or** fewer than 3 seasons show reliable
   positive b2, **stop pursuing a fundamental-model betting edge** and treat
   the market-aware / residual stack as the betting workhorse. The fundamental
   forecaster remains for ratings integrity and totals structure.
