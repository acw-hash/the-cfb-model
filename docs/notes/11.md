# Task 11 — Tempo, possession, and situational builders

## Built

- `src/ncaa_quant/features/builders/tempo.py` — adjusted plays/game, situation-neutral
  seconds/play, pass/rush rate over expectation, expected-possessions regression
  artifact (fit/save/load/predict), `TempoFeatureBuilder` +
  `ExpectedPossessionsFeatureBuilder` (PIT via `filter_event_time` + injectable
  `history`).
- `src/ncaa_quant/features/builders/situational.py` — rest/short-week/bye, haversine
  travel, signed timezone crossing, altitude delta, surface / surface-change,
  neutral site, week/month, conference, rivalry / post-rivalry / lookahead;
  `SituationalFeatureBuilder` with `entity_id = game_id`.
- `configs/rivalries.yaml` — 76 hand-curated school-name pairs.
- `src/ncaa_quant/features/registry.yaml` — tempo + expected_possessions +
  situational features with hypotheses (78 total features after Task 10+11).
- Tests: `tests/unit/test_tempo_situational.py`.

## Decisions / ambiguities

1. **Situation-neutral seconds/play exclusions** (documented in module docstring):
   garbage time; end-of-half (`period ∈ {2,4}` and `clock ≤ 120`); kneel/spike
   play types; hurry-up (`elapsed < 12s` between snaps on the same drive);
   rush/pass snaps only.
2. **Pass-rate OE.** Empirical cell means by
   `(down, distance-bin, margin-bin, clock-bin, period)`; residual
   `is_pass − E[pass|sit]`. Rush OE = −pass OE.
3. **Expected possessions.** `sklearn.linear_model.LinearRegression` on
   `home_pace, away_pace, home_pass_rate, away_pass_rate` → total drive count.
   Artifact is JSON (intercept + coefficients). Applied PIT from precomputed
   season-to-date rates; materializer injects the feature frame.
4. **Only 2023 staged.** Multi-season OOS MAE uses synthetic seasons in tests;
   real-data acceptance uses time-ordered **week** holdout within 2023
   (train ≤10, test ≥11) and is flagged as such.
5. **Situational `event_time`.** Knowable-at = max(prior kickoffs) for both
   teams, else kickoff−14d, always `<` kickoff — so pre-kickoff `as_of` sees
   the row under strict `<` filtering.
6. **Altitude / travel.** Away-focused for non-neutral; neutral averages both
   teams' home→game haversine / tz / altitude deltas.
7. **Scope extras.** Deliverables required registry, rivalry YAML, tests, notes;
   also `__init__.py` exports (same pattern as Task 10). Did not modify
   `DataConfig` (`ewma_half_life_tempo` already present).
