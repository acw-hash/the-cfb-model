# Task 04 — Odds snapshot ingester (AUDIT-10 / amended)

## Built

Completes Task 4 on top of AUDIT-8 raw capture (`docs/notes/04a.md`):

- **Normalization** of archived Odds API payloads to `odds_snapshots` with
  `snapshot_source='live'`, `decision_point=null`, and `n_books_available`.
- **CFBD crosswalk** (`odds_cfbd_game_crosswalk`): Odds event → CFBD `game_id`
  via normalized team pair + kickoff within ±36h. Ambiguous matches are
  `quarantined` (null `game_id`), never guessed. Prior matched `odds_event_id`
  is reused so a one-day postpone keeps one canonical id and continuous
  snapshot history (AUDIT-6.3 fixture).
- **Dedupe** on `(game_key, book, market, side, line, price, captured_at_minute)`.
- **Team-name map** in `configs/team_names.yaml` (fixtures in unit tests).
- **Prefect** `ingest_odds` migrated from `mode=raw_capture` →
  `normalize_and_stage` (raw archival still happens first via
  `run_odds_raw_capture`). Cron unchanged: `0 0,4,8,12,16,20 * * *` UTC.
- **CLI** `ncaa-quant ingest odds --once` runs the full path.
- **`@pytest.mark.live`** on the live network smoke; CI / `make test` use
  `-m "not live"`.

## Decisions / ambiguities

1. **Canonical identity** is CFBD `game_id` (AUDIT-6). Derived `game_key`
   (`{season}:{home}:{away}:{YYYY-MM-DD}`) is matcher input only.
2. **Crosswalk `event_time`** is match/ingest time, not kickoff — future
   commence times must not violate `event_time <= ingested_at`.
3. **2026 schedule not yet staged:** live pulls write crosswalk rows as
   `unmatched` (`game_id` null) until CFBD games for 2026 exist; snapshots
   still stage with null `game_id` (schema-legal).
4. **Raw archival before parse** is shared with 4a; full ingest calls
   `run_odds_raw_capture` then normalize/crosswalk/stage.
