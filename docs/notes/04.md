# Task 04 — Odds snapshot ingester

## Built

- Schema correction (sanctioned): `OddsSnapshotsSchema` gained non-null
  `game_key` and tz-aware `captured_at`. `price` remains American odds (units
  documented). `event_time` stays the PIT knowable-at column and is populated
  equal to `captured_at` at ingest time without collapsing the two fields.
- `src/ncaa_quant/ingestion/odds_api.py`: httpx client for
  `americanfootball_ncaaf` with tenacity retries (5×, exp backoff, 429/5xx/
  timeout only), rate-limit budget guard on `x-requests-remaining`, configurable
  books/markets. Raw archival to `data/raw/odds_api/{date}/{stamp}.json` before
  parse. Normalize → minute-level dedupe → `ParquetStore` append.
- `configs/team_names.yaml` + `normalize_team_name` / `make_game_key`.
- Prefect flow `ingest_odds` in `pipelines/odds.py` with cron from
  `pipeline.odds_ingest_cron` and failure hook stubbed to structlog.
- CLI: `ncaa-quant ingest odds --once`.
- Config knobs on `DataConfig` / `PipelineConfig` + YAML.
- Tests in `tests/unit/test_odds_api.py` (+ schema tests in `test_data_layer.py`).

## Decisions / ambiguities

1. **game_key format:** `{season}:{home}:{away}:{YYYY-MM-DD}` with canonical
   team names and UTC kickoff date. Spec required determinism, not the delimiter.
2. **API markets → schema markets:** `spreads`→`spread`, `totals`→`total`,
   `h2h`→`h2h`.
3. **Unmapped team names:** casefold map lookup, then mascot-suffix strip, then
   whitespace-normalized original. Expand `team_names.yaml` as mismatches appear.
4. **Rate-limit guard:** tracks last `x-requests-remaining`; refuses the *next*
   call when remaining < `odds_rate_limit_reserve` (default 50). First call with
   unknown remaining is allowed.
5. **CLI without `--once`:** exits 2 and points at Prefect for scheduled runs.
6. **`game_id`:** left null until CFBD id linkage exists (Task 5+).

## Correction to Task 3

See also the append in `docs/notes/03.md`. `event_time` must not double as
`captured_at`; both columns are required on odds snapshots.
