# Task 02 — Config and core utilities

## Built

- Layered YAML under `configs/`: `base.yaml`, `data.yaml`, `ratings.yaml`,
  `betting.yaml`, `pipeline.yaml`, plus empty `configs/models/.gitkeep`.
- `src/ncaa_quant/config.py`: OmegaConf merge + pydantic-settings loader with
  precedence base < domain YAML < `NCAA_QUANT_*` env < CLI `overrides`.
  Typed section models (`PathsConfig`, `DataConfig`, `RatingsConfig`,
  `BettingConfig`, `PipelineConfig`, `AppConfig`). Secrets via
  `SecretsSettings` / `CFBD_API_KEY` + `ODDS_API_KEY` only — never on
  `AppConfig`, so `dump_config` cannot leak them.
- `utils/seeding.py`: `set_global_seed` for `random`, NumPy, `PYTHONHASHSEED`,
  `LIGHTGBM_RANDOM_SEED`, `XGBOOST_RANDOM_SEED`; `SeedManifest` JSON-serializable.
- `utils/logging.py`: structlog JSON, `run_id` context binding, redaction
  processor for keys matching `/key|token|secret|password/i`.
- `utils/timeutils.py`: UTC-only helpers (`to_utc`, `season_of`, `week_of`,
  `as_of_bound`, `assert_tz_aware`) with NAIVE-DATETIME-FORBIDDEN guard.
- Tests in `tests/unit/` covering four-level precedence, secret dump/log
  redaction, seed reproducibility, DST conversions, and Jan-2 → prior season.

## Decisions / ambiguities

1. **Week numbering:** Week 1 Monday = Labor Day (first Monday of September,
   UTC weeks Mon–Sun). Pre–Week-1 dates clamp to Week 0 (CFBD Week Zero bucket).
   Spec did not define the calendar; this is the smallest CFBD-aligned rule.
2. **Feb–Jul `season_of`:** mapped to the upcoming season (calendar year). Spec
   only required January bowls → prior season.
3. **PLACEHOLDER config values** (spec named the knob, not the number):
   - `data.end_season` = 2025
   - `data.cfbd_requests_per_second` = 2.0
   - `data.odds_api_requests_per_second` = 1.0
   - `data.ewma_half_life_*` / `shrinkage_k_efficiency` midpoints of §4.4 ranges
   - `ratings.process_noise_scale` = 0.05, `obs_noise_scale` = 0.15
   - `betting.bowl_edge_multiplier` = 1.5
   - `betting.max_bets_per_week` = 10
   - `betting.max_exposure_per_team` = 0.05
   - `betting.min_model_market_agreement` = 7.0 (points)
   - `betting.max_weekly_exposure` = 0.10
   - `pipeline.weekly_pipeline_timeout_hours` = 2.0
4. **GBDT env seed names:** `LIGHTGBM_RANDOM_SEED` / `XGBOOST_RANDOM_SEED` are
   project conventions for later training code to read; the libs do not natively
   honor these env vars alone.
5. **Config env prefix:** non-secret overrides use `NCAA_QUANT_` with `__`
   nesting (e.g. `NCAA_QUANT_BETTING__MIN_EDGE_SIDES`).
