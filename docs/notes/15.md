## Formula

```
x1 = (1−α)·last_posterior + α·conference_mean     (α=0.30)
x2 = returning_pct · last_posterior                 (elasticity absorbed in w2)
x3 = talent_rating_scale · z(talent_composite)
x4 = portal_net_rating                              (0 if pre-2021 or missing)
x5 = new_hc_flag · (x3 − x1)                        (pull toward talent)
x6 = qb_carryover                                   (1/0; missing → 0 + var↑)

prior_mean = intercept + Σ w_i x_i
prior_var  = base_var · (1 + turnover_scale · (1 − returning_pct))
           + missing_var_penalty · n_missing

crossover_games (50/50) = obs_var_eff / prior_var
```

Weights fit by OLS of early-season rating (after first 3 postgame updates) on
`{x1…x6}` over train seasons 2015–2022; held out 2023 and 2024.

## Decisions / ambiguities

1. **Scope vs deliverable 3.** Task says `priors.py` only. Did **not** edit
   `state_space.run_filter` (still uses soft `apply_season_regression`) or
   `efficiency.resolve_priors`. Wiring is via the injection APIs above; callers
   must pass `prior_lookup=` / preseason states. Auto-injection into
   `run_filter` season boundaries needs a one-site change in Task 14 code —
   flagged, not done.
2. **`obs_var_eff=0.20`.** Calibrated so clean 40%/85% returning land at
   crossover ≈4.0 / 7.3 games (§9.6 “roughly 5–7 with variation”). Not the
   raw Kalman `r_epa_base²` (that would wash out in ~1–2 games under Task 14’s
   prior scale).
3. **QB carryover.** No historical `qb_status` backfill → feature is always
   missing in the acceptance fit (`w6=0`, SE=0). Each team still pays the
   missing-input variance penalty. Manual QB table can populate this later.
4. **Defense returning.** CFBD returning is offense-oriented; `defense_pct` is
   often null → `returning_adj` for `def_epa` is identically 0 in the fit
   (`w2=0`). Offense returning works; def relies on last-regressed + talent.
5. **Portal.** Pre-2021 absence is structural (no penalty). In-era null portal
   net widens variance. Fitted `w4` is small but positive with SE < |w|.
6. **Talent mapping.** Within-season z-score × `talent_rating_scale=0.08`
   into EPA-ish units; slope is a starting elasticity, weight `w3` refits.
7. **Early target.** First 3 chronological postgame posteriors (not CFBD week
   labels — bowls reuse week numbers).

## Acceptance — prior-vs-evidence crossover

```text
PRIOR_VS_EVIDENCE_CROSSOVER season=2023 dim=off_epa
CROSSOVER team=New Mexico State returning=0.843 prior_var=0.04285 games_50_50=4.67
CROSSOVER team=Arkansas State returning=0.179 prior_var=0.07605 games_50_50=2.63
ILLUSTRATION ret=0.40 var=0.05000 crossover=4.00
ILLUSTRATION ret=0.85 var=0.02750 crossover=7.27
```

Clean 40% vs 85% illustration matches §9.6 (≈4 vs ≈7). Real teams also pay
missing-input penalties (QB always missing here), so empirical crossovers sit
somewhat earlier than the clean schedule — high-continuity still persists
longer than low-continuity.
