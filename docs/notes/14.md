# Task 14 — State-space (Kalman) rating engine

## Built

- `src/ncaa_quant/ratings/state_space.py` — v1-minimal Kalman filter with
  configurable `state_dims` (v1.1 7-dim is a config append), joint game update,
  informativeness-scaled EPA noise, FCS pooled prior, weekly Q + event-triggered
  inflation (`qb_change` / `coordinator_change` / `manual`), ±2.5σ innovation
  winsorization, season soft-regression, history table + `posterior_asof`,
  Q grid tune, simulation / parameter-recovery helpers.
- `src/ncaa_quant/ratings/diagnostics.py` — standardized innovations, 3×
  same-signed >2σ review flags, filter health (`mean≈0`, `var≈1`; report
  misspecification, do not silently retune).
- Tests: `tests/unit/test_state_space.py`.
- Acceptance harness: `scripts/_state_space_acceptance_14.py` (cache under
  `data/tmp/state_space_acceptance_14/`).

## Formula (measurement / update)

Joint state for a game: `[x_home, x_away, hfa_global, hfa_dev_home]`.

```
epa_h = off_h − def_a + hfa_global + hfa_dev_h + ε     (HFA dropped if neutral)
epa_a = off_a − def_h + ε
st    = st_h − st_a + ε_st                             (skipped if ST EPA missing)
pace  = 0.5·(pace_h + pace_a) + ε                      (obs = mean_plays/ref − 1)
margin = margin_scale · (off_h − def_a − off_a + def_h + hfa) + ε_m

σ²_epa = r_epa_base² · (ref_plays / n_plays)
```

Predict: `P ← P + Q` (identity dynamics). Update: Joseph-form Kalman with
winsorized innovations at ±`residual_winsor_sigma`. Cross-team posterior
covariance discarded after each game (independent-team storage).

## Decisions / ambiguities

1. **Observations for the full history run.** Task asks for garbage-filtered
   per-play EPA; staged lake only has partial seasons. Acceptance uses CFBD
   advanced-box `offense_epa` (PPA) via `build_game_observations_from_advanced`.
   PBP path exists as `build_game_observations_from_plays` for production once
   plays are staged. ST EPA is usually missing on advanced → ST observation
   skipped; pace uses default 70 plays when counts absent.
2. **Q tune.** Global scale scan on 2018–2022 only (fast). Best scale = 0.5×
   default diagonal → fitted Q below. Per-dim Optuna-free scan is implemented
   but not used in acceptance (`dims=()`).
3. **Between-season priors.** Task 15 owns real priors; here soft regression
   (`season_regression=0.30`) toward 0 plus variance inflation.
4. **def_epa sign.** Same as ridge: higher `def_epa` = more EPA suppressed =
   better defense. Rankings sort descending.
5. **Filter health.** Innovation variance 0.57 (n=41k) is below 1 — R is
   somewhat large / over-dispersed predictive. Reported, not silently retuned
   (§9.5). Mean z ≈ 0.02 is fine. Not flagged misspecified under default band
   `[0.5, 2.0]`.
6. **End-of-season `week`.** Many bowl/CFP rows carry CFBD `week=1`; ordering
   uses `event_time`, not week number.
7. **Scope.** Only `state_space.py` + `diagnostics.py` (+ tests/notes/script).
   Did not edit `configs/ratings.yaml` / `RatingsConfig`.
