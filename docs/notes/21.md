# Task 21 — Evaluation metrics and reporting

## Built

- `src/ncaa_quant/evaluation/metrics.py` — Tier 1–4 suite (§7.3): CLV, CRPS,
  log-loss/Brier (with de-vigged market baselines), Cox calibration
  slope/intercept, PIT, interval coverage/width, MAE/RMSE, ATS/OU/SU accuracy,
  DIAGNOSTIC slice tables (§7.2 item 3), weekly error curves, and economic
  simulation (flat / ¼-Kelly / ½-Kelly bankroll paths + max-drawdown bootstrap).
- `src/ncaa_quant/evaluation/significance.py` — week block bootstrap, iid
  bootstrap (for correlation comparison), paired block bootstrap
  (champion−challenger), and the anti-metric `RateWithCI` /
  `format_rate_with_ci` guard.
- `src/ncaa_quant/evaluation/reports.py` — HTML weekly report (predictions,
  edges, confidence, rating movements) and HTML backtest report (metric tables
  with CIs, reliability/PIT plots, weekly error curves, slice tables, equity
  curves, SHAP summary table).
- Tests: `tests/unit/test_evaluation_metrics.py`.

## Decisions / ambiguities

1. **Market CRPS.** Closing lines do not publish a full predictive distribution.
   Market CRPS is an optional argument (`market_crps_margin` /
   `market_crps_total`); when omitted the market column is NaN but still present
   so every probabilistic row keeps a model/market schema. Log-loss and Brier
   always compare against de-vigged closing probabilities when columns are
   present.
2. **SHAP.** No `shap` dependency (would need an ask-first add). Reports accept
   a precomputed `shap_summary` DataFrame and render it; missing input prints
   an explicit placeholder.
3. **Slice columns.** Expected names:
   `conference_slice`, `p5_g5`, `favorite_dog`, `totals_bucket`, `ranked`,
   `bowl`, `rivalry`, `weather` — overridable via `slice_columns=`.
4. **Economic DD bootstrap.** Max-drawdown CIs resample week blocks of per-bet
   PnL and rebuild a cumulative path; this approximates pathwise DD under block
   dependence without a full re-Kelly re-simulation inside each draw.
5. **Hard 1.5% stake guard** in reporting Kelly paths mirrors Task 20’s staking
   cap so half-Kelly bankroll sims cannot explode on thin fixtures.
