# Task 03 — Storage layer and data schemas

## Built

- `src/ncaa_quant/data/schemas.py`: pandera `DataFrameModel`s for games, plays,
  drives, advanced_box, lines_historical, odds_snapshots, teams, venues, coaches,
  rosters, returning_production, recruiting, portal. Shared UTC `event_time` /
  `ingested_at` with `event_time <= ingested_at`. §8 range checks on points,
  spreads, and totals where those columns exist.
- `src/ncaa_quant/data/storage.py`: `ParquetStore` with hive partitions
  `(season, week)` for game-grained tables and `(season)` for reference tables;
  `write_partition` / `read` / `query` (DuckDB views over Parquet). Atomic
  temp+`os.replace` writes; byte-identical rewrite is a no-op (hash short-circuit).
- `src/ncaa_quant/data/asof.py`: sole sanctioned `as_of_join` — strict
  `right[ts_col] < as_of` via `merge_asof(..., allow_exact_matches=False)`;
  rejects missing `ts_col` and tz-naive timestamps.
- Directory placeholders: `data/raw/cfbd/`, `data/raw/odds_api/` (+ existing
  staged/features/predictions). Layout documented in `docs/data_layout.md`.
- Tests in `tests/unit/test_data_layer.py`.

## Decisions / ambiguities

1. **Column inventories** are CFBD-shaped minimal cores for later ingestion tasks;
   not every CFBD field is modeled yet — widen schemas in Task 5+ as endpoints
   are wired.
2. **`as_of` argument** accepts a timezone-aware scalar **or** a left-frame column
   name (needed for per-game kickoff bounds). Spec listed a single `as_of` param.
3. **`odds_snapshots.event_time`** is the capture instant (`captured_at` synonym);
   Task 4 may add an explicit alias column if desired.
4. **Reference tables** also carry `event_time`/`ingested_at` so as-of joins work
   uniformly (spec required them on fact tables; applying to all staged schemas
   is the PIT-safe default).
5. **Parquet determinism**: sorted columns + mergesort rows + snappy; hash compare
   skips replace when bytes match. PyArrow version here rejects
   `allow_truncated_truncation` on `write_table` — omitted.
6. **mypy**: `pandas` / `pyarrow` lack stubs in the locked env; imports use
   `# type: ignore[import-untyped]` inside `data/` only (did not change
   `pyproject.toml`).

## Correction (Task 4)

`OddsSnapshotsSchema` originally treated `event_time` as synonymous with capture
time and lacked `game_key`. Task 4 corrected this (approved cross-task edit):

- Added non-null `game_key` (stable cross-source join key; `game_id` remains a
  nullable CFBD convenience column).
- Added distinct tz-aware `captured_at`. For live odds, ingest sets
  `event_time == captured_at` numerically, but the columns stay separate so
  later sources that diverge cannot silently break PIT joins.
- Kept column name `price` for American odds (Task 4 deliverable text described
  the field, not a rename).
