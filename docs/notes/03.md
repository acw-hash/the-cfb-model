# Task 03 — Storage layer and data schemas

## Built

- `src/ncaa_quant/data/schemas.py`: pandera `DataFrameModel`s for games, plays,
  drives, advanced_box, lines_historical, odds_snapshots, teams, venues, coaches,
  rosters, returning_production, recruiting, portal (plus later-widened
  weather / talent / qb_status). Shared UTC `event_time` / `ingested_at` with
  `event_time <= ingested_at`. §8 range checks on points, spreads, and totals.
- **AUDIT-6 canonical game identity:** CFBD numeric `game_id` is the only
  canonical key. `OddsCfbdGameCrosswalkSchema` (`odds_cfbd_game_crosswalk`) is
  registered now; population is Task 4 / Task 5. Derived `game_key` is matcher
  input only on odds rows and the crosswalk.
- `src/ncaa_quant/data/storage.py`: `ParquetStore` with hive partitions
  `(season, week)` for game-grained tables and `(season)` for reference tables
  (including the crosswalk); `write_partition` / `read` / `query` (DuckDB).
  Atomic temp+`os.replace`; byte-identical rewrite is a no-op (hash short-circuit).
- `src/ncaa_quant/data/asof.py`: sole sanctioned `as_of_join` — strict
  `right[ts_col] < as_of` via `merge_asof(..., allow_exact_matches=False)`;
  rejects missing `ts_col` and tz-naive timestamps.
- Directory placeholders: `data/raw/{source}/`, `data/staged/`, `data/features/`,
  `data/predictions/`. Layout in `docs/data_layout.md`.
- Tests in `tests/unit/test_data_layer.py`.

## Decisions / ambiguities

1. **Column inventories** are CFBD-shaped minimal cores for later ingestion;
   widen in Task 5+ as endpoints are wired (Task 3 notes historically allowed
   this).
2. **`as_of` argument** accepts a timezone-aware scalar **or** a left-frame
   column name (needed for per-game kickoff bounds). Spec listed a single
   `as_of` param.
3. **`odds_snapshots`:** `game_id` nullable until crosswalk resolves; `game_key`
   retained as matcher input (AUDIT-6). `captured_at` is distinct from
   `event_time` (live: numerically equal; columns stay separate).
4. **Crosswalk partition:** season-only (reference), so a postponed game keeps
   one row / one CFBD id across week shifts.
5. **Crosswalk `match_status`:** `matched` | `quarantined` | `unmatched`;
   matched rows require non-null `game_id`.
6. **Reference tables** also carry `event_time`/`ingested_at` so as-of joins
   work uniformly.
7. **Parquet determinism:** sorted columns + mergesort rows + snappy; hash
   compare skips replace when bytes match.
8. **mypy:** `pandas` / `pyarrow` lack stubs; `# type: ignore[import-untyped]`
   inside `data/` only.
