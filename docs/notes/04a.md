# Task 04a — Odds raw capture (fast path)

## Built

Task 4 deliverable 2 only (AUDIT-8 / DESIGN fast path `1 → 2 → 4a`):

- `run_odds_raw_capture` in `src/ncaa_quant/ingestion/odds_api.py`: live Odds
  API fetch → verbatim write to `data/raw/odds_api/{date}/{captured_at}.json`.
  Shares `OddsAPIClient` retries (5× exponential on 429/5xx/timeout) and the
  `odds_rate_limit_reserve` guard. No normalize / dedupe / Parquet.
- CLI `ncaa-quant ingest odds --once` routes to raw capture for now.
- Prefect flow `ingest_odds` serves on `pipeline.odds_ingest_cron`
  (`0 0,4,8,12,16,20 * * *` UTC) in `mode=raw_capture`.
- Full `run_odds_ingest` (normalize + stage) remains for the rest of Task 4 next
  session; it reuses raw capture so archival still happens first.

## Decisions / ambiguities

1. **4a scope:** schedule persists raw JSON only. Normalization, CFBD game-key
   crosswalk, dedupe, and staged Parquet are deferred (Task 4 remainder).
2. **Filename stamp:** `YYYYMMDDTHHMMSSffffffZ` UTC microsecond — matches the
   existing archival helper; ISO-ish and filesystem-safe.
3. **Response body scrub:** raw file is the API response body (no `apiKey` query
   param). Confirmed on live smoke (`contains_api_key_param=False`).
