# Task 06 — Weather and venue enrichment

## Built

- [`src/ncaa_quant/ingestion/weather.py`](../../src/ncaa_quant/ingestion/weather.py):
  venue enrichment from CFBD `/venues` + `configs/venues_overrides.yaml`,
  Open-Meteo archive + forecast clients, kickoff-hour matching in venue-local
  timezone, dome sentinels + `weather_applicable`, forecast/actual separation,
  raw archive under `data/raw/open_meteo/{date}/`, coverage report helper.
- Schema: `WeatherSchema` (game-grained); `VenuesSchema` gained `surface` and
  `timezone` (kept CFBD `latitude`/`longitude`/`dome` names — Task 6's
  `is_dome` maps to `dome`).
- CFBD `normalize_venues_payload` fills `surface` from `grass` and leaves
  `timezone=None` for enrichment to complete.
- CLI: `ncaa-quant ingest weather --seasons …` and `--forecast-upcoming`.
- Config: `venues_overrides_path`, `open_meteo_requests_per_second`.
- Tests in `tests/unit/test_weather.py`.

## Decisions / ambiguities

1. **Column names.** Kept CFBD `latitude`/`longitude`/`dome` rather than renaming
   to Task 6's `lat`/`lon`/`is_dome` — avoids breaking staged CFBD venues and
   Task 5 normalizers. Overrides YAML accepts both spellings (`lat`/`latitude`,
   `is_dome`/`dome`).
2. **Timezone inference.** Primary USPS-state → IANA map; overrides for
   international / split-zone edge cases. Missing timezone on an FBS host is a
   hard error (same severity as missing lat/lon). Aviva Stadium (Dublin,
   `venue_id=3504`) is in `venues_overrides.yaml` as `Europe/Dublin`.
3. **Dome sentinels.** `temp_c=21`, wind/precip/snow=0, humidity=50,
   `precip_prob=0`, plus `weather_applicable=False`. Downstream must key off the
   flag.
4. **`snow` units.** Open-Meteo `snowfall` is cm; stored as `snow` in cm.
5. **`precip_prob`.** Percent (0–100). Archive responses often omit it → null
   on actuals; forecasts populate it when present.
6. **`event_time`.** Actuals = kickoff UTC; forecasts = `captured_at`.
7. **Merge writes.** Weather partitions merge by `(obs_kind, game_id)` for
   actuals and `(obs_kind, game_id, captured_at)` for forecasts so actuals never
   overwrite forecasts and distinct forecast pulls are retained.
8. **Supporting edits** (approved): `schemas.py`, `cfbd.py` venue columns,
   `cli.py`, `config.py` / `data.yaml`, `data_layout.md`, tests, notes.
