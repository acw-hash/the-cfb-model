  structural OOF-only assertion (`is_out_of_fold` must be True on every row);
  ensemble σ via law of total variance

- `src/ncaa_quant/distribution/key_numbers.py` — empirical offset kernel from

- `src/ncaa_quant/distribution/simulate.py` — seeded MC (default 100k draws),

## Nested OOF stacking — structural guarantee

```python
# ensemble.assert_oof_only / fit_nnls_stack
if flag_column not in frame.columns:
    raise EnsembleError(...)          # missing guarantee → refuse
if not np.all(frame[flag_column]):
    raise EnsembleError(... in-fold)  # any False → refuse
```

NNLS cannot fit without an explicit all-True `is_out_of_fold` column. There is
no code path that silently treats in-fold rows as OOF.

## Decisions / ambiguities

1. **Metrics live in `distribution/simulate.py` for now.** Full evaluation
   reporting is Task 21; acceptance needed CRPS / log-loss / Brier / plots
   inside this task's modules. Helpers are thin and reusable.
2. **Ensemble σ.** `Var_k(μ_k)` is weighted by NNLS weights when available,
   else uniform; aleatoric term is the σ-head squared. Members without their
   own σ do not contribute an `E[σ_k²]` term beyond the dedicated head.
3. **Key-number kernel.** Weights = relative frequency of integer residual
   offsets vs mean count (min_count gate). Continuous Normal mass at each
   integer is reweighted and renormalized — no hardcoded {3,7,10,14} bumps.
4. **Joint sampling with kernel.** Margins from discrete PMF; totals from
   conditional Normal given a continuous latent margin draw (preserves ρ in
   expectation). Spec was silent on the conditional step.
5. **Epistemic mixture.** Accepts `posterior_feature_draws` shaped
   `(S, n_games, n_features)` plus a caller-supplied `mapping_fn` — does not
   import or modify `state_space.py` (out of scope). Default S = 50.
6. **Thin-data Platt thresholds.** `n < 200` or `< 10` unique rounded probs
   (documented defaults; forceable via `force_kind`).
7. **Synthetic acceptance baselines.** Elo and “market” are fixture
   constructions (logistic of noisy margin; proportionally de-vigged inflated
   raw probs), not Task-13 Elo on real games or real closing books. Beating
   the synthetic market here is **not** a claim of real edge — report for
   pipeline honesty only. Task 23 / 21 will use real closes.
