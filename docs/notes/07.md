## Decisions / ambiguities

1. **Expected game counts.** Expected = unique `game_id` count in the `games`
   partition (completed rows). Dependent tables (`plays`, `drives`,
   `advanced_box`) must cover that set.
2. **Drive-points tolerance = 8** (one TD+PAT). Not loosened further despite
   widespread CFBD drive-point incompleteness — quarantines are intentional
   findings (see acceptance below).
3. **Box score points.** Task 5 `normalize_advanced_payload` always sets
   `advanced_box.points = None`. Score-consistency is enforced when points are
   present (fixtures); on real 2023 data the check is vacuous. **Prior-task gap
   (not patched):** advanced box does not carry final points from CFBD.
4. **Play sequence.** No dedicated sequence column in staged plays. Use
   `play_id` as proxy. Period-monotone check only when all `play_id`s in a drive
   are non-negative — CFBD negative play_ids are opaque and reverse-sort under
   ascending order (would false-quarantine).
5. **Line open/close ≥ 20** is `severity=flag` (FLAGGED), never quarantines.
6. **CLI exit code.** Non-zero when any partition is QUARANTINED so CI/Makefile
   gates can fail closed; soft flags alone do not fail the process.

### Real-data findings (checks not loosened)

| Finding | Severity | Scope |
|---|---|---|
| `pbp_drive_points_reconcile` | fail / QUARANTINED | drives weeks 1–13, 15 (14 partitions). ~1–22 games/week where offense drive-point sums disagree with finals by > 8. Common deltas of 7/14 suggest missing PAT / defensive scores in CFBD drive `points`. |
| `line_open_close_move` | flag / FLAGGED | lines_historical week 10 — 2 book/game moves ≥ 20 pts. |
| GE schema/ranges, temporal, referential, completeness | pass | games, plays, venues, advanced_box, most lines weeks. |

`games`, `venues`, `plays`, and `advanced_box` partitions for 2023 passed hard
checks. Downstream should skip quarantined `drives` partitions via
